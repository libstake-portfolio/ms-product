# 코드 컨벤션

> 반복해서 쓰이는 코드의 형태를 고정해 둔 곳. 왜 그렇게 하는지는 [아키텍처 문서](../architectures/CLAUDE.md)가 소유하고, 여기에는 **어떻게 쓰는지**만 남긴다.

## 문서

| 문서 | 다루는 것 |
| --- | --- |
| [저장 모델 선언](./orm-entity.md) | 저장 모델 파일의 구성, 필드 유형별 선언 형태, 이름 규칙 |
| [포트 선언](./port.md) | 포트 파일의 구성과 이름 규칙 |

## 이 영역의 문서를 쓸 때

- 템플릿은 자리표시자로 쓴다. 실제 도메인의 이름을 예제에 넣으면 코드가 바뀔 때 문서가 먼저 낡는다.
- 규칙마다 **왜**가 아니라 **무엇을**을 적는다. 근거가 필요하면 해당 아키텍처 문서의 절을 가리킨다.
