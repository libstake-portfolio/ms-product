# 서비스 개요

> 이 서비스가 무엇을 위해 있고, 누가 쓰고, 무엇을 하지 않는가.
>
> 경계를 왜 여기에 그었는지는 [서비스 경계](../architectures/service-boundaries.md)가 소유한다.

---

## 무엇을 위한 서비스인가

**무엇을 파는지**를 정의한다. 파는 대상 하나하나가 어떤 것이고, 어떤 카테고리에 속하고, 고객이 무엇을 고를 수 있고, 그 선택의 결과로 어떤 배리언트가 존재하는지가 여기서 정해진다.

커머스의 다른 서비스들은 이 서비스가 정한 대상을 가져다 쓴다. 수량을 세는 쪽도, 값을 매기는 쪽도, 화면에 내거는 쪽도 "무엇이 존재하는가"를 스스로 정하지 않고 이 서비스의 답을 받는다.

## 누가 쓰는가

**운영자.** 상품을 등록하고 정보를 고치고, 카테고리를 관리하고, 더 이상 팔지 않는 것을 정리한다. 이 서비스가 지원하는 기능은 대부분 운영자가 하는 일이다.

**다른 서비스.** 파는 대상이 무엇인지 알아야 하는 쪽이 참조한다. 이 서비스에 무언가를 써넣지는 않는다.

고객은 이 서비스를 직접 쓰지 않는다. 고객이 보는 화면은 이 서비스가 정한 대상 위에 값과 수량과 진열이 얹혀서 만들어진다.

## 무엇을 하지 않는가

| 하지 않는 것 | 이 서비스가 답하지 않는 질문 |
| --- | --- |
| 수량 | 지금 몇 개 남았는가 |
| 값 | 얼마인가 |
| 판매 여부 | 지금 살 수 있는가 |
| 진열 | 지금 어느 화면 어느 묶음에 걸려 있는가 |
| 주문 | 누가 무엇을 샀는가 |

이 질문들은 파는 대상이 정해진 **다음에** 붙는 것들이고, 대상 자체와는 다른 속도로 바뀐다.
