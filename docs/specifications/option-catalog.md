# 옵션 정의

> 운영자가 상품에 붙일 옵션과 그 값을 미리 만들어 두는 일.
>
> 여기 쓰인 말은 [용어](./glossary.md)를 따른다.

---

## 이 문서가 다루는 업무

고객이 무엇을 기준으로 고를지는 상품마다 새로 정의하지 않는다. 운영자가 옵션과 고를 값들을 한 벌 만들어 두면, 여러 상품이 그것을 가져다 쓴다.

옵션은 상품보다 먼저 존재하고, 어떤 상품에도 붙지 않은 채로도 존재할 수 있다.

## 흐름

1. 옵션을 만든다. 무엇을 기준으로 고르는지를 이름으로 적는다.
2. 그 옵션 안에서 고를 수 있는 값을 하나씩 더한다.
3. 상품이 이 옵션을 가져다 붙인다.

값 목록은 고르기 위한 재료의 전체 목록이다. 상품은 그중 일부만 가져다 쓰고, 가능한 조합을 다 만들지도 않는다.

## 지원해야 하는 기능

### 옵션 만들기

이름만 받는다. 값은 만든 뒤에 더한다.

옵션 이름은 옵션마다 달라야 한다는 요구를 두지 않는다.

### 옵션 이름 고치기

이름만 바뀐다. 이 옵션을 이미 붙여 둔 상품들의 구성은 그대로다.

### 값 더하기, 이름 고치기, 없애기

옵션 하나가 가질 수 있는 값은 **100개**까지다.

| 막히는 경우 |
| --- |
| 같은 옵션 안에 같은 이름의 값이 이미 있을 때 |
| 그 옵션에 없는 값을 고치거나 없애려 할 때 |
| 100개를 넘길 때 |
| 없애려는 값을 이미 어떤 배리언트가 고르고 있을 때 |

값의 이름은 같은 옵션 안에서만 겹치지 않으면 된다. 다른 옵션에 같은 이름의 값이 있는 것은 막지 않는다.

쓰이고 있는 값을 없애면 그 값을 고른 배리언트가 무엇을 뜻하는지 읽을 수 없게 되고, 하류가 거기 매달아 둔 것도 갈 곳을 잃는다. 값을 없애려면 그 값을 쓰는 상품에서 먼저 걷어내야 한다.

## 파급

| 일어난 일 | 알려야 하는 것 |
| --- | --- |
| 옵션이 만들어졌다 | 이름 |
| 옵션 이름이 바뀌었다 | 바뀐 이름과 바뀌기 전 이름 |
| 값이 더해졌다 | 어떤 옵션의 어떤 값인지 |
| 값 이름이 바뀌었다 | 바뀐 이름과 바뀌기 전 이름 |
| 값이 없어졌다 | 어떤 옵션의 어떤 값이었는지 |
