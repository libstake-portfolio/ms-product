# 운영

> 서비스를 **어떻게 실행하는가**를 다루는 곳. 무엇을 만들었는지는 [아키텍처 문서](../architectures/CLAUDE.md)가 소유하고, 여기에는 실행에 필요한 것만 남긴다.

---

## 문서

| 문서 | 다루는 것 |
| --- | --- |
| [로컬 실행](./local-development.md) | 로컬에서 서비스를 띄우고 동작을 확인하는 방법 |
| [실행 환경 계약](./runtime-contract.md) | 실행 환경이 서비스에 제공해야 하는 것과, 서비스가 그 대가로 보장하는 것 |

## 이 영역의 문서를 쓸 때

- 실행 환경이 무엇이든 성립하는 약속과, 로컬에만 해당하는 편의를 섞지 않는다. 전자는 계약 문서가, 후자는 로컬 문서가 소유한다.
- 설정 키의 목록은 [환경 파일 안내](../../envs/README.md)가 소유한다. 여기에 옮겨 적지 않는다.
